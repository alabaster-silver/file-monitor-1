## File Monitor

This is kind of just a rudimentary project I wanted to try out, so it's nothing overly complicated. 
Code could definitely be refined, but I'm not great at Python yet, so it was a good project just to try out. 
I added notes (probably more than necessary) just so that I remember what I was actually trying to do on a given line, hopefully they make sense. 
Okay, all this code is really doing is just generating a hash for a given file (can be any file type!!). 
Access the singlefile-monitor-test.py and edit the text near the bottom if you want to test this out for yourself.
The singlefile-monitor.py file is the same as the singlefile-monitor-test.py file but without the testing portion at the bottom. 
WIP is the directory-monitor.py file that will generate hashes for every individual file in a given directory and store them in a .json file.
